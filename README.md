# 大数分解可视化工具（Large-number-decomposition）

输入一个很大的正整数 N（可以远超普通程序能快速分解的规模），程序对**每个数量级 10^k**：
从 **10^k 起逐个向上扫描，找出该数量级的前 3 个质数**（可能要测试很多个数）；
途中经过的合数也按所选模式分解（紧凑显示下折叠为摘要），并给出每个数的用时和总计用时。

## 功能特性

- **两种分解模式**（可单选）：
  - 完整质因数分解；
  - 仅分解为两个数相乘——找到一个非平凡因子 d，给出 `n = d × (n/d)`，证明 n 是合数即可（快得多）。
- **紧凑显示（默认）**：每个数量级只列出找到的 3 个质数（红色）与异常情况，
  其余合数折叠为一行摘要；勾选「列出合数明细」可逐个查看每个数的分解。
- **多进程并行**：默认按 CPU 逻辑核心数开启计算进程（48 核机器默认 48 进程，可调），
  每个数量级一个任务并行扫描，结果按数量级顺序显示。
- **组内对齐排版**：同一数量级内所有 `=` 号对齐、「用时」列对齐（中文按 2 倍宽度计算）。
- **大数缩写显示**：`10^21`、`10^21+1`、`5×10^103`、`9.090909×10^101`，不再是一长串 0。
- **质数红色标出**；限时内未能完成 / 被跳过的内容橙色标出并给出已找到的因子。
- **限时作用于每个数量级，可选「不限时」**；运行中可 暂停/继续、跳过当前、停止。
- **慢任务进度**：所有进行中数量级的实时状态合并显示在结果框下方的一行绿字里原地刷新
  （阶段：扫描中 / 素性检测 / p-1 预处理 / 找因子，如 `10^166 9s 找因子`），
  每找到一个质数会在结果区单独提示一行；找因子 rho 为随机算法，无法给出可靠的剩余时间估计。
- **资源监控**：界面底部实时显示 CPU 型号/线程数、整机 CPU 占用、内存总量/可用量，
  以及本程序的进程数、折合核数、内存占用。

## 使用方法

**方式一（推荐）**：双击 `大数分解工具.exe`（或 `启动大数分解工具.bat`）。

**方式二**：`python factor_gui.py`（需 Python 3.8+，纯标准库，无第三方依赖）

命令行参数：

```
python factor_gui.py --demo       # 自动演示 N = 10^12
python factor_gui.py --selftest   # 命令行自检（含多进程流水线/跳过/停止测试）
```

输入支持 `10^100`、`2^64`、`1e50` 等写法，或直接粘贴整数（上限 20 万位）。

提示：数量级越大，找到 3 个质数需要扫描的数越多（由素数定理，平均约 2.3×k 个），
10^103 数量级平均要扫 700 个数左右。大数量级建议配合「每组限时」或「跳过当前」使用。

## 算法说明

试除（10 万以内素数表）→ Miller-Rabin 素性检测（10^24 以内结果确定性正确）→
Pollard p-1 → Pollard rho（Brent 变体）。

如实说明：随机几百位的合数可能任何程序都无法在可接受时间内分解。本程序对此的处理是：
用 Miller-Rabin **确定**是否质数（红色「质数」）；确认为合数但限时内分解不动的，
橙色列出已找到的因子和剩余部分（标注位数）；位数极大（数千位以上）的自动降级为只试除并注明，
保证永不卡死。

```
pip install pyinstaller
pyinstaller --noconfirm --clean --onefile --windowed --name 大数分解工具 factor_gui.py
```
