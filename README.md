# 大数分解可视化工具（Large-number-decomposition）

输入一个很大的正整数 N（可以远超普通程序能快速分解的规模），程序对**每个数量级 10^k**
取该数量级的前三个数 **10^k、10^k+1、10^k+2**（最后一组不超过 N），按所选模式分解，
并给出每个数的分解用时和总计用时。

## 功能特性

- **两种分解模式**（可单选）：
  - 完整质因数分解；
  - 仅分解为两个数相乘——找到一个非平凡因子即给出 `n = d × (n/d)`，证明 n 是合数即可（快得多）。
- **多进程并行**：默认按 CPU 逻辑核心数开启计算进程（48 核机器默认 48 进程，可调），流水线分发、结果按数量级顺序显示。
- **大数缩写显示**：`10^21`、`10^21+1`、`7.240316×10^29`，不再是一长串 0。
- **质数红色标出**；限时内未能完全分解 / 被跳过的数橙色标出并给出已找到的因子。
- **限时可选「不限时」**；运行中可 暂停/继续、跳过当前、停止。
- **慢任务中间过程**：单个数计算超过 2 秒后，持续打印当前阶段（试除 → Miller-Rabin 底数进度与 ETA → Pollard p-1 → Pollard rho 轮次与速率）。
- **资源监控**：界面底部实时显示 CPU 型号/线程数、整机 CPU 占用、内存总量/可用量，以及本程序的进程数、折合核数、内存占用。

## 使用方法

**方式一（推荐）**：双击 `大数分解工具.exe`（或 `启动大数分解工具.bat`）。

**方式二**：`python factor_gui.py`（需 Python 3.8+，纯标准库，无第三方依赖）

命令行参数：

```
python factor_gui.py --demo       # 自动演示 N = 10^12
python factor_gui.py --selftest   # 命令行自检（含多进程流水线/跳过/停止测试）
```

输入支持 `10^100`、`2^64`、`1e50` 等写法，或直接粘贴整数（上限 20 万位）。

## 算法说明

试除（10 万以内素数表）→ Miller-Rabin 素性检测（10^24 以内结果确定性正确）→
Pollard p-1 → Pollard rho（Brent 变体）。

如实说明：随机几百位的合数可能任何程序都无法在可接受时间内分解。本程序对此的处理是：
用 Miller-Rabin **确定**是否质数（红色「质数」）；确认为合数但限时内分解不动的，
橙色列出已找到的因子和剩余部分（标注位数）；位数极大（数千位以上）的自动降级为只试除并注明，
保证永不卡死。

